# Claude Code eval suite (generated)

Every case directory here is generated by `scripts/build_evals.py` from `evals/questions.json`. Edit the JSON, then regenerate. CI fails if this folder drifts.

Graders per case:

- `skill.md`: whether the `ecosystem-guide` skill fired (should-trigger cases) or stayed silent (should-not-trigger cases, scored in both arms).
- `expect.md`: judge rubric built from the case's `expect` list.
- `route.md`: whether the expected reference file was opened (indicator only).

Run from the repository root; see the README for commands. `results/` is git-ignored.
