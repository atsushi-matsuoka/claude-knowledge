# Learning provenance and limits

Last verified: 2026-09-27

## What this version actually contains

This is an initial practice layer, not a claim that an assistant completed Claude Academy. The Academy catalogue and course outlines establish the intended learning sequence; an outline alone does not establish lesson completion.

Reviewed for this implementation: textual sections of Anthropic's public Real world prompting lesson 3 (prompt engineering process); the prompting overview and general prompting guidance; official evaluation, effective-agent and context-engineering guidance. These were converted into concise original procedures and synthetic examples. No notebook exercises or Academy quizzes were executed.

Academy lesson bodies could not be obtained through the available access path in this session. Public catalogue/outline information was visible, while attempted full course pages returned empty content or access errors. This does not establish that every learner needs a login. AI Fluency foundations, the full prompting curriculum, API/tool-use exercises and the rest of Academy remain incomplete.

## Promotion rule

For each future lesson, record its exact source, retrieved section, access status, verification date, source type (Academy lesson / official educational notebook / current docs), learned principle, original workflow, original example and proposed evaluation. Mark read, exercised and measured separately. Never change all curriculum rows to completed because documentation was added.

Use current official docs for product facts. Treat educational notebooks with older model examples as method resources, not current model/API instructions. Record substantive contradictions rather than silently blending them.
