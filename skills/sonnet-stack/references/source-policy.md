# Source policy

Last verified: 2026-09-23

## Priority

1. Current first-party Anthropic documentation relevant to the exact product surface.
2. Anthropic release notes / official engineering posts for newly announced behavior.
3. Academy-derived notes for learning structure and durable practice.
4. Other sources only for experience reports or comparison, clearly labeled as such.

## Volatile facts

Always treat the following as time-sensitive: model names and IDs, pricing, context windows, plan limits, usage caps, feature availability, beta/GA status, CLI command behavior, supported platforms, and security/data-retention settings.

When live verification is available, verify these before answering or editing the knowledge pack. If it is not available, state the date of the saved reference and avoid presenting it as guaranteed current.

## Copyright / note taking

Do not copy Academy lessons or official documentation wholesale. Keep original summaries, short necessary quotations only, and links to the source.
