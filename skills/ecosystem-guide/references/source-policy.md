# Source policy

Last verified: 2026-09-26

## Priority

1. Current first-party Anthropic documentation for the exact surface.
2. Anthropic release notes, changelogs and news posts for newly announced behavior.
3. This pack's dated notes and Academy-derived practice.
4. Anything else (forums, blogs, social posts) only as labeled anecdote; never adopt a product fact from it without first-party confirmation.

When first-party pages disagree, prefer the page that is most specific to the surface and most recently updated, and say that they disagree.

## Official entry points

| Topic | Start here |
|---|---|
| Claude Code (all features, settings, plugins, skills) | https://code.claude.com/docs/llms.txt (index), pages at `https://code.claude.com/docs/en/<page>` |
| Claude Code release notes | https://code.claude.com/docs/en/changelog |
| API / Platform, Agent Skills spec, models, pricing | https://platform.claude.com/llms.txt (index), https://platform.claude.com/docs/en/about-claude/models/overview, https://platform.claude.com/docs/en/about-claude/pricing |

| Plans, usage limits, account and admin questions | https://support.claude.com |
| Announcements | https://www.anthropic.com/news |

Most doc pages also serve clean Markdown when `.md` is appended to the URL, which is cheaper to read.

## Notes and copyright

Do not copy Academy lessons or documentation wholesale. Write short original summaries, quote only what is necessary, and keep the source URL.
