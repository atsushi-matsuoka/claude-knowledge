# Workflow: answer a Claude ecosystem question

1. Classify the surface: claude.ai, Claude Code, API/Platform, or cross-agent.
2. Classify freshness: stable concept or volatile fact.
3. Read only the relevant local reference.
4. For volatile facts, verify current official Anthropic docs when possible.
5. Answer with the exact surface and date context when ambiguity matters.
6. Separate verified fact from recommendation or inference.
7. If current verification is unavailable, say so and cite the saved verification date rather than guessing.
