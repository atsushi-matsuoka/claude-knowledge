# Google Drive role

Google Drive is the learning inbox and human-facing archive, not the canonical reviewed knowledge store.

Recommended folder structure:

```text
Claude Knowledge Pack/
├── Academy Notes/
└── Exports/
```

Use `Academy Notes/` for rough course notes, screenshots, PDFs, and study artifacts. Promote only concise, verified summaries into GitHub.

Use `Exports/` for optional snapshots or packaged releases of the GitHub knowledge pack.

Do not edit the same canonical knowledge file independently in Drive and GitHub. That creates split-brain versioning.
